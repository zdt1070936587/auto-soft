## 1. 阶段目标

阶段 1 把「能进系统、能管人」做完，为阶段 2 的动态功能提供登录身份与菜单容器。

必须同时满足：

1. 未登录访问业务接口返回未认证；登录成功拿到 JWT，后续请求自动带上。
2. 内置四种角色均可登录，侧栏菜单按角色不同。
3. 管理员可维护用户、角色，并为角色勾选菜单。
4. 关闭公开注册，账号仅由管理员创建。
5. 登录页有太阳系三维动效，弱动画偏好与 WebGL 失败可降级。
6. Controller 零业务；密码 BCrypt 存储，日志与接口响应均不出现明文密码或完整 token。
7. `/api/health` 与 `/actuator/health` 仍匿名可访问。

## 4. 角色与权限模型

内置角色编码写死为枚举，种子数据必须存在，**禁止删除这四条角色**（可改名称/备注，不可改 `code`）。

| 角色编码 | 名称 | 阶段 1 可见菜单 | 说明 |
| --- | --- | --- | --- |
| `SUPER_ADMIN` | 超级管理员 | 全部系统菜单 | 可管用户/角色/菜单授权；鉴权时绕过权限码 |
| `ADMIN` | 管理员 | 用户管理、角色管理 | 不可把他人提权为 `SUPER_ADMIN` |
| `DEVELOPER` | 开发者 | 工作台（占位） | 阶段 3 再开放工作室；本阶段仅占位页 |
| `USER` | 普通用户 | 工作台（占位） | 阶段 2 起使用已发布功能 |

权限码（按钮级，挂在 `sys_menu.permission`）：

| 权限码 | 用途 |
| --- | --- |
| `system:user:list` | 用户分页 |
| `system:user:create` | 新建用户 |
| `system:user:update` | 改用户、停用、分配角色 |
| `system:user:delete` | 逻辑删除用户 |
| `system:role:list` | 角色列表 |
| `system:role:create` | 新建角色 |
| `system:role:update` | 改角色 |
| `system:role:delete` | 逻辑删除自定义角色 |
| `system:role:grant` | 给角色分配菜单 |

路由鉴权：前端按菜单 `path` 生成动态路由；后端每个写接口用权限码校验。列表接口同样校验，禁止只靠前端藏按钮。

## 5. 命名与约定（本阶段补充）

| 项 | 取值 |
| --- | --- |
| Token 头 | `Authorization: Bearer <jwt>` |
| Access Token 有效期 | 8 小时（配置项，默认 28800 秒） |
| JWT 算法 | HS256，密钥放配置，**禁止提交生产密钥** |
| 密码算法 | BCrypt（Spring Security `BCryptPasswordEncoder`） |
| 登录失败文案 | 统一「用户名或密码错误」（防账号枚举） |
| 停用账号 | 「账号已停用」 |
| 公开注册 | `autosoft.auth.register-enabled=false`，接口直接拒绝 |
| 默认管理员 | 用户名 `admin`，初始密码见种子 SQL 注释，**仅本地**；登录后建议改密 |
| 逻辑删除 | `deleted`：0 正常 / 1 已删；MyBatis-Plus `@TableLogic` |
| 用户状态 | 枚举 `ENABLED=1` / `DISABLED=0` |

新增 `ResultCode`：

- `UNAUTHORIZED(401, "unauthorized")`
- `FORBIDDEN(403, "forbidden")`
- `USERNAME_PASSWORD_ERROR(401, "用户名或密码错误")` — 或复用 401 并自定义 msg

未登录与 token 过期：HTTP 仍可 200 + `code=401`（与现有 `R` 风格一致，前端拦截跳转登录），也可以 HTTP 401。**本阶段选定：HTTP 401，body 仍为 `R`**，便于 axios 区分网络错误与鉴权失败。需在 `GlobalExceptionHandler` / Security 入口统一写出 `R`。

### 7.6 种子数据

1. 四条内置角色，`builtin=1`。
2. 用户 `admin`，密码为 BCrypt(`admin123`)，绑定 `SUPER_ADMIN`。SQL 内注释写明「仅开发库」。
3. 用户 `demo_admin` / `demo_dev` / `demo_user`（可选，方便验收三种菜单），密码同样 `admin123`，分别绑 `ADMIN` / `DEVELOPER` / `USER`。若觉得种子过多，至少保证 `admin` + 文档说明如何手工加另外三个。
4. 菜单树：

BCrypt 不要在 SQL 里手写错哈希：可在迁移后用一次性 Java 或文档给出已生成的哈希（实施时用 `BCryptPasswordEncoder.encode` 打出再写入 SQL）。

## 8. 后端详细设计

### 8.1 依赖（阶段 1 引入）

在 `auto-soft-framework` 或 `auto-soft-boot`：

- `spring-boot-starter-security`（若 Boot 4.1 拆分为 servlet 变体，以 Central 实际坐标为准，**不要降回 Boot 3**）
- `spring-boot-starter-aspectj`（Boot 4 将原 `starter-aop` 更名）
- `mybatis-plus-spring-boot4-starter`（版本已在父 POM `3.5.15`）及分页所需的 `mybatis-plus-jsqlparser`
- JWT：优先 `com.nimbusds:nimbus-jose-jwt`（避免 Jackson 2 与 Boot 4 Jackson 3 冲突）。不要引入 `jjwt-jackson`（Jackson 2）。

`auto-soft-system` 依赖 `framework`，写 Mapper / Service / Controller。

健康检查的 `JdbcTemplate` 可保留，不强制改成 MP。

### 8.2 配置项（`application.yml` / `application-dev.yml`）

```yaml
autosoft:
  auth:
    register-enabled: false
  jwt:
    secret: "dev-only-change-me-32bytes-min-secret!"
    expire-seconds: 28800
    issuer: auto-soft
```

`jwt.secret` 开发占位可提交；生产用环境变量或 `application-local.yml`。长度至少 32 字节（HS256）。

MyBatis-Plus：

- `mapper-locations` 若用注解 SQL 可省略 XML
- 下划线转驼峰
- 逻辑删除值 1 / 未删 0

### 8.3 Security 链

`SecurityConfig`：

1. Session **STATELESS**
2. CSRF 关闭（纯 API + JWT）
3. CORS 沿用现有 `WebMvcConfig`（或迁移到 Security CORS，二选一，禁止配两套互相打架）
4. 放行：`POST /api/auth/login`、`GET /api/health`、`GET /actuator/health`、`OPTIONS /**`
5. 其余 `/api/**` 需认证
6. 过滤器：`JwtAuthenticationFilter` 解析 Bearer，成功则写入 `SecurityContext`
7. 未认证 / 无权限走自定义入口，写出 `R`，不要默认 HTML 登录页

当前用户：`SecurityUtils.currentUserId()` 从 `Authentication` 取，Controller 需要用户 ID 时调用工具，不解析 token。

### 8.4 JWT（`JwtManager`，放 framework）

职责：签发、解析、校验过期。claims 至少：`sub`（userId）、`username`、`iat`、`exp`。角色列表可选（菜单以接口为准，避免 token 过大、权限变更不生效）。

**权限变更立刻生效**：每次请求按 userId 查库或短缓存（阶段 1 可每次查库；用户量小）。不要把权限码写进 JWT。

### 8.5 分层与类

包：`com.autosoft.system`。

| 类 | 层 | 职责 |
| --- | --- | --- |
| `AuthController` | Web | login / me / password |
| `UserController` | Web | 用户 CRUD、状态、分配角色 |
| `RoleController` | Web | 角色 CRUD、分配菜单 |
| `MenuController` | Web | 当前用户菜单树、全量树（授权用） |
| `AuthService` | Service | 登录编排（见下） |
| `UserService` | Service | 用户业务 |
| `RoleService` | Service | 角色业务 |
| `MenuService` | Service | 菜单树组装 |
| `PasswordManager` | Manager | 只做 encode / matches，便于测 |
| `UserMapper` 等 | Mapper | MP BaseMapper |
| `UserDO` / `UserVO` / `UserCreateDTO` | 对象 | Controller 不返回 DO |

登录 `AuthService.login` 主方法只写步骤：

1. `loadEnabledUser(username)`
2. `verifyPassword(raw, encoded)`
3. `issueToken(user)`
4. `touchLastLogin(userId)`
5. `buildLoginVO(user, token)`

改密步骤：校验旧密码 → 校验新旧不同 → 更新哈希 → （可选）提示重新登录。

用户创建步骤：校验用户名唯一 → 校验角色存在且当前人有权授予 → 编码密码 → 插入用户 → 写 `sys_user_role`。

删除用户：不可删自己；不可删最后一个 `SUPER_ADMIN`；逻辑删除。

删除角色：`builtin=1` 拒绝；有用户绑定时拒绝或同时清理关联（本阶段：**有绑定则拒绝删除**）。

授予 `SUPER_ADMIN`：仅当前用户已是 `SUPER_ADMIN`。

### 8.6 API 清单

统一前缀 `/api`，成功 `code=0`。

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | 匿名 | `{ username, password }` → `{ token, tokenType, expiresIn, user }` |
| GET | `/api/auth/me` | 登录 | 当前用户 + roles + menus |
| PUT | `/api/auth/password` | 登录 | `{ oldPassword, newPassword }` |
| POST | `/api/auth/register` | 配置关闭则 403 | 阶段 1 可实现但默认关闭 |
| GET | `/api/users` | `system:user:list` | 分页，Query：username/status |
| POST | `/api/users` | `system:user:create` | 创建 |
| PUT | `/api/users/{id}` | `system:user:update` | 改昵称等，不改密码 |
| PUT | `/api/users/{id}/password` | `system:user:update` | 管理员重置密码 |
| PUT | `/api/users/{id}/status` | `system:user:update` | 启用/停用 |
| PUT | `/api/users/{id}/roles` | `system:user:update` | `{ roleIds: [] }` |
| DELETE | `/api/users/{id}` | `system:user:delete` | 逻辑删 |
| GET | `/api/roles` | `system:role:list` | 列表或分页 |
| POST | `/api/roles` | `system:role:create` | |
| PUT | `/api/roles/{id}` | `system:role:update` | 不可改 `code`（内置） |
| DELETE | `/api/roles/{id}` | `system:role:delete` | |
| GET | `/api/roles/{id}/menus` | `system:role:list` | 已授权菜单 id |

| GET | `/api/menus/tree` | `system:role:grant` 或超级管理员 | 全量树供勾选 |

校验：用户名 `^[a-zA-Z][a-zA-Z0-9_]{3,31}$`；密码 8～32 位，至少含字母和数字。用 `@Validated` DTO。

登录 VO **不得**包含 `password`。用户列表同样脱敏。

### 8.7 权限注解

自定义 `@RequiresPermission("system:user:list")` + AOP：取当前用户权限码集合（`SUPER_ADMIN` 直接通过）。不要在 Controller 里写 `if`。无权限抛 `BizException(FORBIDDEN)` 或 `AccessDeniedException` 由 Handler 转 `R`。

### 8.8 MyBatis-Plus 审计

`AuditMetaObjectHandler`：insert 填 `createdAt`/`updatedAt`/`createdBy`/`updatedBy`/`deleted=0`；update 填 `updatedAt`/`updatedBy`。用户 ID 从 `SecurityUtils` 取，匿名场景（登录）填 `0`。

分页：`PaginationInnerInterceptor`（PostgreSQL）。`PageQuery` 已有，Service 转 MP `Page`。

## 9. 前端详细设计

### 9.1 依赖

- `three` 及 `@types/three`
- 不引入额外 UI 登录模板库

### 9.2 路由

| path | layout | 说明 |
| --- | --- | --- |
| `/login` | 无 | 太阳系登录，已登录则跳 `/dashboard` |
| `/dashboard` | Admin | 工作台 |
| `/system/users` | Admin | 用户 |
| `/system/roles` | Admin | 角色 |
| `/` | | 已登录 → dashboard，否则 → login |
| 阶段 0 的 `/` 健康页 | | **改为** `/dev/health` 或登录后工作台内链到健康接口；不要让未登录首页仍是健康卡片 |

路由守卫：无 token 且非 `/login` → `/login`；有 token 无菜单权限的 path → 工作台或 403 页（阶段 1 做简单 403 页即可）。

动态路由：登录后根据 `menus` 注册 `MENU` 类型；`DIR` 只做侧栏分组。

### 9.3 axios

`http.ts`：

- 请求拦截：有 token 则加 `Authorization`
- 响应：`code !== 0` 提示 msg
- HTTP 401：清 token，跳 `/login`（登录接口自己的 401 只提示「用户名或密码错误」，不循环跳转）
- HTTP 403：提示无权限

token 存 `localStorage` 键 `autosoft.token`。「记住登录」勾选则 localStorage，否则 sessionStorage。

### 9.4 登录页（重点）

全屏、深空背景、**无**后台 sider。

**动效（`SolarSystemCanvas.vue`）**

- Three.js：透视相机、太阳点光、行星沿椭圆或圆轨道公转、自转、星空粒子、极缓慢相机漂移。
- 不要求天文数据完全真实，但必须能看出「太阳系在转」，禁止纯 CSS 旋转一张图冒充。
- `requestAnimationFrame` 循环；组件卸载必须 `dispose` 几何体/材质/渲染器，避免泄漏。
- `prefers-reduced-motion: reduce`：停公转，只留静态星空或低帧太阳。
- WebGL `getContext` 失败：CSS 径向渐变 + 少量星星，登录卡仍可用。

**登录卡**

- 右侧（或居中偏右）玻璃拟态：半透明、模糊、细边框。
- 字段：账号、密码、记住登录、登录按钮。
- 错误：文案 + 卡片轻微抖动（CSS animation，约 300ms）。
- 提交中按钮 loading，防重复提交。

### 9.5 后台 Layout

- 左侧：logo + 按 `menus` 渲染的 `a-menu`（支持一层 DIR + MENU）
- 顶栏：当前用户昵称、角色、改密入口、退出
- 内容区：`RouterView`
- 退出：清 token，回 `/login`

## 13. 风险与处理

| 风险 | 处理 |
| --- | --- |
| Boot 4 Security starter 坐标变化 | 查 4.1.x Central，用官方 starter，不手写旧 `WebSecurityConfigurerAdapter` |
| jjwt 拉入 Jackson 2 | 改用 nimbus-jose-jwt |
| MyBatis-Plus 与 Boot 4 | 已锁定 `mybatis-plus-spring-boot4-starter`；分页插件方言指定 PostgreSQL |
| 太阳系性能差 | 限制像素比 `max 2`；减少星星数量；低端机检测 `renderer.capabilities` |
| 种子 BCrypt 与编码器 rounds 不一致 | 用同一 `BCryptPasswordEncoder` 生成哈希再写入 SQL |
| 菜单与路由不同步 | 前端 path 与 `sys_menu.path` 一份契约，写进本节 9.2 |
